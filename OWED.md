# Owed

Owed is a consumer refund tracker. Its first job is to turn a promised refund into a dated record, a follow-up draft, and a confirmed outcome.

Run locally with `python3 -m http.server 8715 --directory public`. The site requires only static hosting; it has no API, database or build step. Users can start blank or try a sample workspace. Real records stay in that browser. The app does not connect accounts, upload data, send reminders or messages, decide eligibility, or charge money.

## Where it can grow

A common case record can support refund delays, billing errors, warranty claims, and later unclaimed money or benefits. Each workflow should have its own evidence checklist, official route, deadline rules and outcome. Build the next case type only after users show up with it and the resolution path is understood. Start with Canada, and specify coverage by provider and jurisdiction rather than implying universal eligibility.

1. Run 20 promised-refund cases with users already pursuing a refund. Record claimed amount, action taken, time and effort to recover it, and whether users would pay after success. Track money users actually confirm receiving separately from promised amounts.
2. Add opt-in reminders and cross-device sync after proving follow-up is the bottleneck. Add optional evidence storage only when retention, deletion and access controls are in place.
3. Test paid help before implementing checkout. Compare a clearly stated fixed price with a capped success fee where appropriate. Keep the tracker useful on its own. Don't charge for speculative savings.
4. Add guided warranty and billing cases, then partner with consumer organizations that see recurring problems. The long-term product is an action layer for money people are owed, with a track record of which steps help people resolve cases.

The name is a working brand; verify trademark availability and domains before a standalone commercial launch.
